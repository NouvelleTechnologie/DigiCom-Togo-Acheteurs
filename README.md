# DigiCom-Togo-Acheteurs
Nous avons mis en place un système de réseau de producteurs et vendeurs de produits locaux. Pour faire face au fléau qui rend difficile la digitalisation et la commercialisation des produits locaux, NEW-TECHK MOBILE CENTER a décidé de créer une application pour rapprocher producteurs, vendeurs et acheteurs sans se déplacer.
